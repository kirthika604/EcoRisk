Joshimath: Human-Activity Risk Amplification

Every disaster tool predicts the event. This shows how human activity is already pushing Joshimath (Chamoli district, Uttarakhand) toward a threshold that has caused failures before — and what changing that activity does to the projected outcome.

Data & sources
  • NDVI / NDBI: Sentinel-2, processed in Google Earth Engine (real, project-collected).
  • Historical rainfall: NASA POWER (MERRA-2 corrected precipitation), 2019–2023 (real, direct source).
  • Live rainfall: Open-Meteo API, fetched at page load (real, live).
  • Rainfall threshold: Kanungo & Sharma (2014), Rainfall thresholds for prediction of shallow landslides around Chamoli-Joshimath region, Garhwal Himalayas, India, Landslides 11, 629–638, DOI 10.1007/s10346-013-0438-9. Primary paper is paywalled — figures taken from a secondary source summarizing it (disclosed openly, see project memory).
  • Subsidence event log: secondary press reporting (Deccan Herald / Outlook India / BusinessToday, Jan 2023) citing an NRSC/ISRO DInSAR report no longer hosted on nrsc.gov.in.
  • Vulnerability index (section 3): illustrative, built for this demo — not a peer-reviewed model.
